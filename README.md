- 🐋 Containerized
- 🪄 CI/CD (Github Action)

## Change Placeholder Value

### In package.json change the following

- docker:build
- docker:start

### In github registry add Repo or Org Vars following

- Vars
  - USERNAME
  - GH_PAT
